实时订单数据分析与推荐平台

围绕模拟订单，练习实时处理、离线采集与推荐方法。这里记录代码中的结构和尝试，不把它描述成已经上线的服务。

技术路径

按代码中的模块整理，不代表所有环节都已经稳定运行。

实时处理
  1. 模拟订单Python 生成数据
  2. Kafka消息上报
  3. Spark Streaming窗口聚合
  4. 可视化WebSocket / ECharts
离线处理
  1. Kafka采集来源
  2. Flume → HDFS写入文件存储
  3. MySQL → HiveSqoop 同步业务数据
01 / 实时

订单数据与实时展示

使用 Python 模拟订单，经 Kafka 传递；Spark Streaming 对数据做窗口聚合，再将结果经 Kafka 发送给 Flask / WebSocket 展示层。ECharts 用来呈现图表。

02 / 离线

采集与入仓

自定义 Flume PollableSource 从 Kafka 读取并处理数据后写入 HDFS；Sqoop 将 MySQL 业务数据同步到 Hive，尝试用 Spark SQL / RDD 统计。

03 / 推荐

推荐方法尝试

练习 Item-Based 和 User-Based 协同过滤，使用余弦相似度 UDF，并在结果写入时考虑幂等 upsert。
