两个完整跑通的项目 · 从实时数仓到法律智能体

01 大数据 · 实时数仓

实时订单数据分析与推荐平台

完整覆盖大数据离线 + 实时两条链路：Python 模拟订单数据源，经 Kafka 上报； Spark Streaming 做窗口聚合，Flume 自定义 Source 落盘 HDFS， Sqoop 把 MySQL 业务库同步进 Hive 中央仓库，最后 Flask + WebSocket + ECharts 实时可视化。

  • 实时链路：Kafka → Spark Streaming(5s 批间隔)→ Kafka → WebSocket 推送
  • 采集链路：自定义 Flume PollableSource 消费 Kafka 并扁平化拆解后写 HDFS
  • 离线链路：Sqoop MySQL → Hive，Spark SQL / RDD 双实现统计口径
  • 推荐算法：Item-Based / User-Based 协同过滤 + 余弦相似度 UDF，幂等 upsert 落库
Kafka Spark Streaming Scala Flume Sqoop Hive HDFS Flask ECharts

02 AI · 法律智能体

LawDesign · 法律智能体平台

基于大模型的法律咨询 / 合同审查 / 诉讼文书生成一体化平台。 monorepo 结构：20+ 个可独立启动的微服务 + React 前端 + Scala 实时风控流处理， 公共能力抽到 shared/ 包统一复用。

  • 微服务集群：鉴权 / 合规审查 / 合同数据 / 风险分析 / 诉讼文书 / 合同模板等 20+ 服务
  • GraphRAG 法律问答：FastAPI 检索服务 + graphrag 知识图谱，Moonshot 案例分析
  • 实时风控：Kafka → Spark Streaming → 风控看板
  • 前端：React + TypeScript + antd(Vite)，shared 包统一 Flask / FastAPI 脚手架
