LawDesign · 法律智能体平台

围绕法律问答、合同审查与文书草拟，尝试组织前端和多个后端服务。这是一份技术练习记录，不是对外提供的法律服务。

练习项目源码暂未公开技术记录 · 非上线说明

技术路径

按代码中的模块整理，不代表所有环节都已经稳定运行。

问答与服务
  1. React 前端页面与交互
  2. Flask / FastAPI业务服务
  3. GraphRAG法律资料检索
风控链路
  1. Kafka数据入口
  2. Spark Streaming流处理
  3. 风控看板结果展示
01 / 结构

多模块练习

使用 monorepo 管理 React 前端、鉴权、合同数据、风险分析、诉讼文书与合同模板等服务。共用配置和服务脚手架整理在 shared 包中。

02 / 问答

法律场景检索

法律问答部分尝试以 FastAPI 提供 GraphRAG 检索接口；另外有案例分析模块，接入 Moonshot。它们是不同的练习模块，不等同于法律建议服务。

03 / 风控

数据链路

项目中还有 Kafka 生产者、Scala + Spark Streaming 流处理以及 Flask 风控看板模块，用来探索实时数据处理。
